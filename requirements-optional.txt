#  crx 코어는 외부 의존이 없다. Python 3.11+ 표준 라이브러리만 쓴다.
#  (tomllib, urllib, dataclasses, concurrent.futures — 전부 stdlib)
#
#  아래는 선택 의존성이다. 없어도 파이프라인은 동작한다.
#
#  ## 폐쇄망 반입 방법
#
#  인터넷이 되는 장비에서 wheel 을 미리 받아 옮긴다.
#
#      pip download -r requirements-optional.txt -d wheels/ \
#          --platform win_amd64 --python-version 312 --only-binary=:all:
#
#  폐쇄망 장비에서:
#
#      pip install --no-index --find-links wheels/ -r requirements-optional.txt
#
#  ## 없으면 어떻게 되나
#
#  tree-sitter 가 없으면 청킹이 휴리스틱 폴백(중괄호 매칭 / 인덴트 추적)으로
#  동작한다. 함수 경계 탐지 정확도가 다소 떨어지지만 파이프라인은 멈추지 않는다.
#  전처리기 조건부(#if) 안에서 괄호가 불균형한 C++ 코드에서 경계를 놓칠 수 있다.
#
#  uvicorn 이 없으면 관제 화면(`python -m crx.viz`)이 표준 라이브러리
#  `http.server` 로 뜬다. 사용자 한둘이 0.4초마다 이벤트를 받아가는 게 전부라
#  성능 차이가 의미를 갖지 않는다. 반입 목록을 줄이고 싶으면 그냥 두어도 된다.
#
#  `python -m crx doctor` 로 현재 상태를 확인하라.
